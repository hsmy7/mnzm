### 1.2 复核结论（F-5 定稿）

1. **五入口中位 0.2591 / 0.2758 / 0.2968 / 0.3448 / 0.3198**（金丹/元婴/化神/炼虚/大乘），均值 ≈ **0.299**；

2. **方案 §3.3 预测「约 27%、实际略高」命中**（单件部分按 2/3 计、套装满套守恒 ⇒ 略高于 27%）——
   **FR7 占比观察项不触发**，登记为条件债 **EQ-I17**（architecture.md「装备线遗留债登记」表；
   触发条件 = 实测低于产品底线或产品要求回约 40%，唯一回补路径 = 直接改数值表）。
3. **带宽 [0.22, 0.40] 定稿**：五入口中位全部带内；带覆盖 p10 下探 0.13 / p90 上探 0.48 的中位锚口径。
   测试 KDoc 与断言消息已由「F4 复核定稿」措辞改为定稿口径（唯一代码触点）。
4. **无隐藏补偿（F-12/FA4）**：中性源主词条基数与副词条档位 F1–F4 四批零改动（F1 幂等重生成零漂移 +
   F3 数值表逐条对偶 Kotlin 字面量 + 本批零数据触点），占比变化全部来自件数 6→4 的自然下降。
5. **EQ-I16 数字刷新**（四部位口径）：① T1@炼气 54.6%（六部位时代）→ **43.4%**（仍结构性越带，语义不变）；
   ② 深化期衰减 渡劫 23.0%/仙人 12.6% → **合体 18.2% / 渡劫 18.5% / 仙人 9.8%**。
