## 4. 归因拆分（方案 §2.1 贡献公式）

```
总退化        best_D − best_B = 882.9 − 661.9 = 221.0 µs（+33.4%）
Δ装备（B→C）  best_C − best_B = 838.7 − 661.9 = 176.8 µs   → 占 80.0%
Δ五行（C→D）  best_D − best_C = 882.9 − 838.7 =  44.2 µs   → 占 20.0%
```

## 5. 分支判定（方案 §2.2）

| 分支 | 判据 | 判定 |
|---|---|---|
| ① 装备侧为主 | Δ装备/总 > 60% | ✅ **80.0% ⇒ 命中分支①** |
| ② 五行侧为主 | Δ五行/总 > 60% | ✗（20.0%） |
| ③ 均匀分摊 | 两者皆 ≤60% | ✗ |
| ④ 环境所致 | best_B ≈ best_D（<5%） | ✗（+33.4%，且 B 点校准通过） |

**结论：+30% 为真实净退化，主体来自装备线 B3 六部位结算路径（每弟子装备段求和），五行六路类型通道仅贡献 20%。⇒ R3 开启，按分支①处置：优化 `disciple_stats.h` 装备段求和 / `EquipBonus` 每旬解析缓存（方案 §6.6"不劣化 >10%"判据目前不满足）。**

R3 验收目标（§5.3）：同一安静窗口下 best 相对 best_D（882.9 µs）**改善 ≥10% 或 ≤800 µs**，且全部 Diff* 与 C++ GTest 逐位一致（禁止改数值语义）。余量触发条件登记：现余量 (1000−882.9)/1000 ≈ 11.7%，< 20% 阈值（800 µs），性能债成立。
