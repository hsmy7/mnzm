# 装备重构批次报告目录

本目录存放 `docs/design/equipment-batches/IMPLEMENTATION-BATCHES.md` 所定义批次的**实施报告**：

| 文件 | 批次 |
|---|---|
| `report-B0.md` | 存档编号规划与冻结守卫 |
| `report-B1.md` | 属性机制重构（单列 + 类型通道 + 固有伤害属性） |
| `report-B2.md` | 孕养类加成丹药退役（R11）+ 补偿 |
| `report-B3.md` | 装备体系原子替换（六部位/套装/升级/词条/删堆叠/删旧装备） |
| `report-B4.md` | 数值对齐与验收 |
| `report-B5.md` | 文档、ADR、双更新日志、债登记 |

## 报告格式（每批必含五节）

1. **做了什么** —— 分类表
2. **验证** —— 门禁**实跑数值原文**（禁止写"应该通过"）
3. **旧用例处置表** —— 删除 / 改断言 / 保留 + 理由
4. **未完成 / 登记** —— 跨批收口项与产品歧义
5. **风险** —— 区分"已核实"与"推测"

> 报告在该批完成时创建；本目录不预置空报告（避免与"未完成"状态混淆）。
> **文档入库义务**：本方案与批次文档曾以未跟踪文件存在、被并行实施流的 `git clean` 清除且无 git 历史可恢复 ⇒ 方案/批次/报告文档**必须提交**。
